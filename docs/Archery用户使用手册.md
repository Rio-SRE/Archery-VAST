## 二、SQL 查询（在线查询）

**路径：** 导航栏 → SQL查询（/sqlquery/）

### 使用步骤

1. 选择目标实例（如 `test-mysql`）
2. 选择数据库（如 `testdb`）
3. 在编辑器中输入 SQL 语句
4. 点击「执行」

### 注意事项

- 仅支持 SELECT / SHOW 类只读语句
- 危险操作（DROP、DELETE、TRUNCATE）会被自动拦截
- 查询结果默认限制 1000 行
- 研发人员只能查询已授权的库表，未授权的会被拒绝
- 如需使用 DESCRIBE，请用 `SELECT * FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_SCHEMA='库名' AND TABLE_NAME='表名'` 替代

## 三、SQL 工单（变更上线）

**路径：** 导航栏 → SQL上线（/sqlworkflow/）

### 提交工单

1. 点击「提交SQL上线工单」
2. 填写工单信息：
   - **工单名称**：简要描述变更目的
   - **目标实例**：选择要执行的数据库实例
   - **目标数据库**：选择具体数据库
   - **SQL 内容**：填写 DDL 或 DML 语句
3. 点击「提交」，工单进入待审核状态

### 工单审批流程

```
提交工单 → Dev-Lead 审核 → 执行上线 → 完成
```

- 提交后工单状态为「待审核」
- 研发负责人（Dev-Lead）审核通过后即可执行
- 执行完成后状态变为 `workflow_finish`

### 工单状态说明

| 状态 | 含义 |
|------|------|
| 待审核 | 已提交，等待 Dev-Lead 审批 |
| 审核通过 | Dev-Lead 已审批，等待执行 |
| 执行中 | SQL 正在执行 |
| workflow_finish | 工单完成 |
| 审核不通过 | Dev-Lead 驳回，需修改后重新提交 |

## 四、查询权限申请

**路径：** 导航栏 → 权限管理 → 权限申请（/queryapplylist/）

### 研发人员申请流程

查询权限无需审批，申请后自动授权。

1. 点击「申请查询权限」
2. 选择目标实例和数据库
3. 提交后系统自动授权，立即可查询

---

## 五、实例管理（仅管理员）

**路径：** 导航栏 → 实例管理（/instance/）

### 功能列表

| 页面 | 路径 | 用途 |
|------|------|------|
| 实例列表 | /instance/ | 查看/添加/编辑数据库实例 |
| 实例账号 | /instanceaccount/ | 管理实例的数据库账号 |
| 数据库管理 | /database/ | 查看实例下的数据库 |
| DB 诊断 | /dbdiagnostic/ | 数据库诊断信息 |

### 添加新实例

1. 点击「添加实例」
2. 填写：实例名称、数据库类型（MySQL/PostgreSQL）、连接地址、端口、用户名、密码
3. 选择资源组
4. 点击「测试连接」确认连通性
5. 保存

---

## 六、审批流程配置（仅管理员）

**路径：** 导航栏 → 工作流管理（/workflow/）

### 当前配置

| 审批类型 | 流程 |
|---------|------|
| SQL 上线 | 提交 → Dev-Lead 审核 → 执行 |
| 查询权限 | 无需审批，自动授权 |

以上审批流对所有资源组（default / production / staging）均生效。管理员可在系统配置中按资源组调整审批节点。

## 八、用户管理（仅管理员）

### 创建新用户

1. 访问 Django Admin：http://39.96.66.171:9123/admin/sql/users/add/
2. 填写用户名、密码、显示名、邮箱
3. 选择权限组（DBA / Dev-Lead / Developer / QA）
4. 选择资源组（控制可见实例范围）

### 资源组

资源组用于隔离不同团队对实例的可见性：

| 资源组 | 可见实例 |
|--------|---------|
| default | 公共/测试实例 |
| production | 生产环境实例（仅 DBA） |
| staging | 预发/测试环境实例 |

将实例分配到对应资源组后，只有属于该资源组的用户才能看到并操作这些实例。

## 十、更新实例账号密码

当前所有实例默认使用统一的数据库连接账号。如果某个实例的账号密码不正确（连接失败），需要手动更新：

### 方法一：通过 Web UI 更新（推荐）

1. 使用 dev_lead 或 admin 登录
2. 进入「实例管理 → 实例列表」（/instance/）
3. 找到需要修改的实例，点击「编辑」
4. 修改「用户名」和「密码」字段为正确的数据库凭据
5. 点击「测试连接」确认连通
6. 保存

### 方法二：通过 Django Admin 更新

1. 访问 http://39.96.66.171:9123/admin/sql/instance/
2. 找到目标实例，点击进入编辑页
3. 修改 `user` 和 `password` 字段
4. 保存
